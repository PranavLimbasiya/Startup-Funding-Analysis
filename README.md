# Startup Funding Analysis Dashboard

An interactive Power BI dashboard for exploring startup funding data. The report is provided as a Power BI `.pbix` file and can be opened with Microsoft Power BI Desktop.

## Dashboard Pages

### 1. Funding Overview
A high-level view of startup funding information and key metrics.

### 2. Location & Rounds
A page focused on the geographical distribution of funding and funding-round analysis.

## Project File

| File | Description |
|---|---|
| `Pranav_PowerBI-DB.pbix` | Power BI report containing the dashboard, report visuals, theme and embedded data model |

## Tools Used

- Microsoft Power BI Desktop
- Power Query (for data preparation)
- DAX (for measures and calculations)

## How to Open the Dashboard

1. Download `Pranav_PowerBI-DB.pbix` from this repository.
2. Install and open Microsoft Power BI Desktop.
3. Open the downloaded `.pbix` file.
4. Explore the **Funding Overview** and **Location & Rounds** report pages.
5. Use the report's available filters and visual interactions to explore the data.
